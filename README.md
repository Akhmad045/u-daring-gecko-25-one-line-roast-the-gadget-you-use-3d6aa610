A single original roast line about the robot vacuum that cleans my home every day: it mapped the whole house in one afternoon, then spent a year ramming the same chair leg like it's personal. `main.py` (Python 3.13, standard library only, no network) writes the line to `/output/entry.txt`, with a gate that checks it is one non-blank line of 1–200 UTF-8 characters and verifies the written file round-trips exactly.
